Описание

MinePack — программа, которая облегчит жизнь мододелам Minecraft. Простой инструмент для создания и редактирования ресурспаков.

У вас обязательно должен быть установлен Minecraft Java Edition. Программа имеет простой и понятный интерфейс.

Возможности

  • Создание ресурспаков с нуля
  • Редактирование существующих ресурспаков
  • Готовые шаблоны для быстрого старта
  • Простой и понятный интерфейс
  • Поддержка всех актуальных версий Minecraft Java
  • Автоматическая упаковка в .zip
