Описание

Программа Scream — Digital Signage Kiosk App. Представляет собой меню, где можно выбрать файлы для показа.

Есть два режима: фото + аудио и видео. Ниже можно установить таймер и комбинацию клавиш для деактивации.

Возможности

  • Два режима показа: фото + аудио и видео
  • Удобное меню выбора файлов
  • Настраиваемый таймер показа
  • Комбинация клавиш для деактивации
  • Подходит для Digital Signage Kiosk
  • Поддержка популярных форматов медиа
