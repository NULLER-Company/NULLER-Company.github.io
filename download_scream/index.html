Описание

Программа Scream является одной из программ Digital Signage Kiosk App. Программа представляет собой меню, где можно выбрать файлы для показа.

Есть два режима: фото + аудио и видео. Ниже можно установить таймер и комбинацию клавиш для деактивации.

Рекомендуется использовать программу в рабочих целях! Не использовать, если вы не прочитали инструкцию! Ознакомьтесь с лицензионным соглашением.

Возможности

  • Два режима показа: фото + аудио и видео
  • Удобное меню выбора файлов
  • Настраиваемый таймер показа
  • Комбинация клавиш для деактивации
  • Подходит для Digital Signage Kiosk
  • Поддержка популярных форматов медиа
